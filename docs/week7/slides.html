Recursive Sum: rSumup1 & rSumup2

Compute 1 + 2 + … + n recursively

Template Code


#include <stdio.h>

int rSumup1(int n);
void rSumup2(int n, int* result);

int main() {
  int n, result;
  printf("Enter a number: \n");
  scanf("%d", &n);
  printf("rSumup1(): %d\n", rSumup1(n));
  rSumup2(n, &result);
  printf("rSumup2(): %d\n", result);
  return 0;
}

int rSumup1(int n) { /* Write your code here */ }

void rSumup2(int n, int* result) { /* Write your code here */ }

rSumup1 — Return Value Approach

Base case: n == 1 → return 1

Recursive: return n + rSumup1(n - 1)


int rSumup1(int n) {
  if (n == 1) {
    return 1;
  }
  return n + rSumup1(n - 1);
}

rSumup1(4) Call Trace

rSumup1(4) = 4 + rSumup1(3) = 4 + 6 = 10
↓
rSumup1(3) = 3 + rSumup1(2) = 3 + 3 = 6
↓
rSumup1(2) = 2 + rSumup1(1) = 2 + 1 = 3
↓
rSumup1(1) n == 1 (base case) return 1

Each call waits for the deeper call to return, then adds n to the result.

rSumup2 — Pointer Approach

Base case: n == 1 → *result = 1

Recursive: get sub-result via pointer, then *result = n + temp


void rSumup2(int n, int* result) {
  if (n == 1) {
    *result = 1;
    return;
  }
  int temp;
  rSumup2(n - 1, &temp);
  *result = n + temp;
}

rSumup2(4, &result) Call Trace

rSumup2(4, &result) temp=6, *result = 4+6 *result = 10
↓
rSumup2(3, &temp) temp=3, *result = 3+3 *result = 6
↓
rSumup2(2, &temp) temp=1, *result = 2+1 *result = 3
↓
rSumup2(1, &temp) n == 1 (base case) *result = 1

Same logic, but results are written through pointers instead of return values.

Recursive Digit: rDigitValue1 & rDigitValue2

Find the k-th digit from the right of a number

Template Code


#include <stdio.h>

int rDigitValue1(int num, int k);
void rDigitValue2(int num, int k, int* result);

int main() {
  int k;
  int number, digit;
  printf("Enter a number: \n");
  scanf("%d", &number);
  printf("Enter k position: \n");
  scanf("%d", &k);
  printf("rDigitValue1(): %d\n", rDigitValue1(number, k));
  rDigitValue2(number, k, &digit);
  printf("rDigitValue2(): %d\n", digit);
  return 0;
}

int rDigitValue1(int num, int k) { /* Write your code here */ }

void rDigitValue2(int num, int k, int* result) { /* Write your code here */ }

Key Idea

The k-th digit from the right of num:

Operation Effect Example (num=12345)
num % 10 Get last digit 12345 % 10 = 5
num / 10 Remove last digit 12345 / 10 = 1234

Strategy: Remove last digit k-1 times, then take % 10 


int rDigitValue1(int num, int k) {
  if (k == 1) {
    return num % 10;
  }
  return rDigitValue1(num / 10, k - 1);
}

rDigitValue1(12345, 3)

12345 → digits: 1 2 3 4 5, k=3 means 3rd from right = 3

rDigitValue1(12345, 3) k≠1 → call(12345/10, 3-1) = 3
↓

↓
rDigitValue1(123, 1) k == 1 (base case) return 123 % 10 = 3

Each recursion strips the last digit (/10) and decrements k. When k == 1, the last digit is the answer.

rDigitValue2 — Pointer Approach


void rDigitValue2(int num, int k, int* result) {
  if (k == 1) {
    *result = num % 10;
  } else {
    rDigitValue2(num / 10, k - 1, result);
  }
}
rDigitValue2(12345, 3, &digit) k≠1 → call(1234, 2, &digit)
↓
rDigitValue2(1234, 2, &digit) k≠1 → call(123, 1, &digit)
↓
rDigitValue2(123, 1, &digit) k == 1 *result = 3

Same pointer result is passed all the way down. The base case writes directly to it.

Question 3

What does this code do?

The Code


#include <stdio.h>

#define BLANK ' '

void saveChar(void);

int main() {
  printf("Enter your word and end it with a space => ");
  saveChar();
  putchar('\n');
  return 0;
}

void saveChar() {
  char ch;
  ch = getchar();
  if (ch != BLANK) {
    saveChar();
  } else {
    putchar('\n');
  }
  putchar(ch);
}

How saveChar() Works

Each call reads one character and saves it on the stack.

If ch != ' ' → recurse deeper (read next char)

If ch == ' ' → stop recursing, print '\n'

After recursion returns, putchar(ch) prints the saved character.

Since deeper calls return first → characters print in reverse order!

Trace: Input = "hello "

↓ Calling phase (reading characters)

ch = 'h' ch != ' ' → call saveChar() putchar('h') ← 6th
ch = 'e' ch != ' ' → call saveChar() putchar('e') ← 5th
ch = 'l' ch != ' ' → call saveChar() putchar('l') ← 4th
ch = 'l' ch != ' ' → call saveChar() putchar('l') ← 3rd
ch = 'o' ch != ' ' → call saveChar() putchar('o') ← 2nd
ch = ' ' ch == ' ' → putchar('\n') putchar(' ') ← 1st

↑ Returning phase (printing characters in reverse)

Output

Enter your word and end it with a space => hello
↑ user types "hello " (with trailing space)

␠olleh
↑ newline from putchar('\n'), then ␠(space) + reversed chars

The code reverses a word using the call stack as implicit storage. Each recursive call "saves" one character; as the stack unwinds, characters are printed in reverse order.

Recursive Count: rCountArray

Count occurrences of a target number in an array

Template Code


#include <stdio.h>

#define SIZE 20

int rCountArray(int array[], int n, int a);

int main() {
  int array[SIZE];
  int index, count, target, size;
  printf("Enter array size: \n");
  scanf("%d", &size);
  printf("Enter %d numbers: \n", size);
  for (index = 0; index < size; index++) scanf("%d", &array[index]);
  printf("Enter the target number: \n");
  scanf("%d", &target);
  count = rCountArray(array, size, target);
  printf("rCountArray(): %d\n", count);
  return 0;
}

int rCountArray(int array[], int n, int a) {
  /* Write your program code here */
}

Key Idea

Base case: n == 0 → no elements left, return 0

Recursive: count in first n-1 elements, then check array[n-1]


int rCountArray(int array[], int n, int a) {
  if (n == 0) {
    return 0;
  }
  int count = rCountArray(array, n - 1, a);
  if (array[n - 1] == a) {
    count++;
  }
  return count;
}

Example: arr = [1, 2, 3, 2, 1], target = 2

rCountArray(arr, 5, 2) → arr[4]=1 ≠ 2
return 2
rCountArray(arr, 4, 2) → arr[3]=2 == 2 ✓
return 1+1 = 2
rCountArray(arr, 3, 2) → arr[2]=3 ≠ 2
return 1
rCountArray(arr, 2, 2) → arr[1]=2 == 2 ✓
return 0+1 = 1
rCountArray(arr, 1, 2) → arr[0]=1 ≠ 2
return 0
rCountArray(arr, 0, 2) → n == 0 (base case)
return 0

Two matches found (indices 1 and 3) → result = 2

Bonus: Memoization

Optimizing recursion by caching results

Fibonacci — Naive Recursion


int fibonacci(int n) {
  if (n == 0) return 0;
  if (n == 1) return 1;
  return fibonacci(n - 1) + fibonacci(n - 2);
}

F(0)=0,   F(1)=1,   F(2)=1,   F(3)=2,   F(4)=3,   F(5)=5,   …

fib(5) — Recursion Tree

fib(5)
├── fib(4)
│   ├── fib(3)
│   │   ├── fib(2)
│   │   │   ├── fib(1) = 1
│   │   │   └── fib(0) = 0
│   │   └── fib(1) = 1
│   └── fib(2) ← repeated!
│       ├── fib(1) = 1
│       └── fib(0) = 0
└── fib(3) ← repeated!
    ├── fib(2) ← repeated!
    │   ├── fib(1) = 1
    │   └── fib(0) = 0
    └── fib(1) = 1

15 total calls — fib(2) computed 3 times, fib(3) computed 2 times!

Time complexity: O(2n) — exponential!

Same subproblems are solved over and over again.

Idea: Memoization

Store results of subproblems so we never recompute them.

1. Create a memory[] array, initialized to -1

2. Before computing, check: memory[n] != -1 ?

3. If cached → return memory[n] immediately

4. Otherwise → compute, store in memory[n], then return

Memoized Fibonacci


#include <stdio.h>
#include <stdlib.h>

int fibonacci(int n, int *memory);

int main() {
  int n;
  scanf("Enter a number n: %d", &n);
  int *memory = (int*) malloc(n * sizeof(int));
  for (int i = 0; i < n; i++) memory[i] = -1;
  printf("Fibonacci of %d is %d\n", n, fibonacci(n, memory));
  free(memory);
  return 0;
}

int fibonacci(int n, int *memory) {
  if (n == 0) return 0;
  if (n == 1) return 1;
  if (memory[n] != -1)       // already computed?
    return memory[n];         // return cached result!
  memory[n] = fibonacci(n - 1, memory) + fibonacci(n - 2, memory);
  return memory[n];
}

fib(5) — With Memoization

  • fib(5) → store mem[5] = 5
    • fib(4) → store mem[4] = 3
      • fib(3) → store mem[3] = 2
        • fib(2) → store mem[2] = 1
          • fib(1) = 1
          • fib(0) = 0
        • fib(1) = 1
      • fib(2) → cache hit: mem[2] = 1
    • fib(3) → cache hit: mem[3] = 2

Only 9 calls! Repeated subproblems return immediately from cache.

Memory Array

After fib(5) completes:

Index 0 1 2 3 4 5
memory[] -1 -1 1 2 3 5

fib(0) and fib(1) are handled by base cases, so memory[0] and memory[1] stay as -1.

Comparison

Naive Memoized

Space O(n) call stack O(n) call stack + array
fib(40) calls 331,160,281 77

Memoization trades a small amount of memory for a massive speedup.
Each subproblem is computed at most once → linear time!
